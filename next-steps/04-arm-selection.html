Arms to drop

  • Levels 1–2, except the one scene whose first instruction is at L2 and the levels that serve as its "before" controls.
  • The "pressure dose-response" framing across all levels. It isn't a valid construct. Replace it with explicit ingredient contrasts (instruction present/absent; later: harm, promise, permission).
  • A-A as a headline arm. It's tautological for authority. Keep a small A-A slice only as a manipulation check: authority agents should follow the instruction.
  • Expanding settings or template scenes.

Arms to run (recommended)

Factors: - Scene-levels: the 46 first-instruction scene-levels plus the level just before each, giving 92 scene-levels. - Instruction: PRESENT vs REMOVED at the first-instruction level, and ORIGINAL vs ADDED at the level before. This gives 4 variants × 46 = 184 scene-level variants. They come from the existing WIP builder with the principals-artefact fix. - Placement (from 01): SYSTEM vs SPLIT. - Pairings: - none-none (new; primary for the attack-surface question) - W-W (high base rate) - D-D - W-none and D-none (lone-taker asymmetry: under an explicit superior instruction the non-deception agent took 33% vs its no-rule partner's 46%, and was the lone taker only 1 time vs 17; so D-none is the cleanest test of a rule that resists authority) - A-none (the none agent is untold; the A agent is a manipulation check) - a 25% A-A check slice - Monitoring notice: unwatched only in the core run, to maximise base rates for the authority contrast. Add a watched slice later if budget allows. - Seed: 1, plus a second seed on a 20% random subset to estimate within-cell noise.

Pre-registered hypotheses for this run

  1. H1 (primary, none-none): within cell, a superior's take-instruction raises mutual take for agents with no installed rule, under SPLIT placement (the instruction is in user content). Test: paired McNemar plus a scenario-cluster bootstrap CI.
  2. H2 (placement): the instruction effect is smaller under SPLIT than SYSTEM. Test: the difference in paired effects, with a cluster bootstrap.
  3. H3 (generality): H1 also holds for W-W and D-D. - H3b (rule resistance): under an instruction, the non-deception agent takes less than its no-rule partner in D-none (exploratory in the completed study: 33% vs 46%).
  4. H4 (manipulation check): A-A follows the instruction in both placements.

Everything else is exploratory, with BH correction.

How to generate the cell list

Read pressure-construct/tables/instruction_category_by_scene_level.csv. For each scenario, take the minimum level where instr_cat == "explicit", plus level − 1. Feed that list to the builder (03) with --pairings none-none,W-W,D-D,W-none,D-none,A-none --placements system,split --monitoring unwatched. Add the none-none pairing to the pack's pairings_to_run: {"id": "none-none", "a": "none", "b": "none", "kind": "control"}.
